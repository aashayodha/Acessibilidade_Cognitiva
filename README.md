# Acessibilidade_Cognitiva
O repositório Acessibilidade_Digital armazena o ciclo prático de auditoria em interfaces web para usuários com TDAH. Utilizando a matriz prescritiva e o checklist de 12 itens do estudo, o espaço documenta códigos HTML/CSS/JS originais e suas respectivas versões corrigidas, visando mitigar a sobrecarga atencional.
